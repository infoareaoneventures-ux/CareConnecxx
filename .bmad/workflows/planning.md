# BMAD Workflow: Planning

## Purpose
Create comprehensive plans for new CareConnex features

## Trigger
/bmad-plan

## Steps

### 1. VISION CLARIFICATION
**Agent:** ProductManager + CareExpert

Define:
- What is the big picture goal?
- How does this align with CareConnex mission?
- What user pain point does this solve?
- What is the desired outcome?

**Output:** Vision statement

---

### 2. USER RESEARCH
**Agent:** UX Designer + ProductManager

Understand users:
- Target user personas (families, caregivers, admins)
- Current workflow pain points
- Competitor analysis
- User interviews/surveys
- Accessibility needs (seniors)

**Output:** User research summary

---

### 3. REQUIREMENTS GATHERING
**Agent:** ProductManager

Document requirements:
- Functional requirements
- Non-functional requirements
- HIPAA compliance requirements
- Accessibility requirements (WCAG)
- Performance requirements
- Integration requirements

**Output:** Requirements document

---

### 4. SOLUTION BRAINSTORMING
**Agent:** All (Party Mode)

Generate ideas:
- Multiple solution approaches
- Creative alternatives
- Technology options
- Integration patterns
- Pros/cons of each

**Output:** Solution options matrix

---

### 5. TECHNICAL FEASIBILITY
**Agent:** Architect

Assess feasibility:
- Technical complexity
- Resource requirements
- Timeline estimates
- Risk assessment
- Dependency analysis
- Infrastructure needs

**Output:** Feasibility assessment

---

### 6. SOLUTION SELECTION
**Agent:** ProductManager + Architect

Select solution:
- Evaluate against criteria
- Cost/benefit analysis
- Risk vs. reward
- Timeline fit
- Resource availability

**Output:** Selected solution + rationale

---

### 7. ROADMAP CREATION
**Agent:** ProductManager

Create roadmap:
- Break into phases/releases
- Define milestones
- Set priorities
- Allocate resources
- Set timelines
- Identify dependencies

**Output:** Feature roadmap

---

### 8. SUCCESS METRICS
**Agent:** ProductManager

Define KPIs:
- Adoption metrics
- Engagement metrics
- Business metrics
- Technical metrics
- User satisfaction

**Output:** Success metrics + measurement plan

---

### 9. COMMUNICATION PLAN
**Agent:** ProductManager

Plan communication:
- Stakeholder updates
- Team communication
- User communication
- Launch announcement
- Training needs

**Output:** Communication plan

---

## Output Deliverables

1. **Vision Document** - Big picture and goals
2. **Requirements Spec** - Detailed requirements
3. **Solution Design** - Selected approach
4. **Roadmap** - Timeline and milestones
5. **Success Metrics** - How we measure success
6. **Communication Plan** - Who needs to know what

---

## Completion Criteria
- [ ] Vision aligned with stakeholders
- [ ] Requirements documented
- [ ] Solution selected
- [ ] Roadmap approved
- [ ] Metrics defined
- [ ] Team ready to execute
